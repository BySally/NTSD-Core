# Беспроводной узел

<BlockImage id="expatternprovider:wireless_hub" scale="6"></BlockImage>

Узел соединяет до **восьми беспроводных линий**. Его можно получить из одного <ItemLink id="expatternprovider:wireless_connect" /> без дополнительных материалов.

Связывайте его с соединителями обычным <ItemLink id="expatternprovider:wireless_tool" />: нажмите по одной точке, затем по другой. Свободный порт выбирается автоматически. Начинать можно с любого конца.

## Управление линиями

Откройте узел пустой рукой. Восемь строк соответствуют его портам. У каждой занятой линии есть координаты удалённой точки и кнопка отключения с крестиком. Если все порты заняты, освободите один перед новым подключением.

Узел потребляет сумму расходов подключённых линий. Каждая удалённая точка оплачивает свою сторону связи отдельно. После отключения линии её расход исключается из суммы; пустой узел энергию не расходует.

Устройства должны оставаться в одном измерении и в загруженных чанках. Дополнительные линии не увеличивают число каналов, доступных через плотный кабель самого узла: учитывайте общую пропускную способность сети.
