# Подключение нескольких точек

<ItemImage id="expatternprovider:wireless_advanced_tool" scale="4"></ItemImage>

Улучшенный инструмент хранит очередь точек для последовательного подключения. Для его создания нужны обычный <ItemLink id="expatternprovider:wireless_tool" /> и четыре звезды Нижнего мира.

В режиме **«Добавление»** нажимайте по нужным соединителям или узлам, чтобы собрать очередь. Переключитесь в режим **«Подключение»** и нажимайте по вторым концам линий: инструмент применяет сохранённые точки по очереди. Текущий режим и содержимое очереди показаны в подсказке предмета.

Shift + ПКМ переключает режим. Для полного сброса настроек поместите инструмент один в сетку крафта: получится чистый инструмент без очереди. Такой же сброс доступен для обычного инструмента.

Инструмент не снимает ограничения самой сети: занятые пары нужно предварительно отключать, у узла есть восемь портов, а связь между измерениями недоступна. Эта дополнительная цель квеста необязательна: для первой пары достаточно обычного инструмента.
