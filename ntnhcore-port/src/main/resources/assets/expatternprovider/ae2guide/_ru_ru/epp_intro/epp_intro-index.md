# Беспроводная МЭ-сеть

Соедините удалённые части сети, не прокладывая кабель между ними. Начните с пары соединителей, а для нескольких направлений используйте узел.

- [Соединитель и обычный инструмент](wireless_connector.md)
- [Узел для восьми направлений](wireless_hub.md)
- [Улучшенный инструмент с очередью](wireless_advanced_setup.md)

Эти устройства передают каналы сети. Для доступа игрока к хранилищу нужен беспроводной терминал, а для соединения разных измерений — квантовый мост.
